# Pictures in this folder

These animal and food pictures come from [Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google.

The project's README says its image resources are under the Apache License, Version 2.0. The license file in
the project itself (copied here as `LICENSE`) is the SIL Open Font License 1.1. Both allow these pictures to be
used and shared, including inside other work, as long as the license notice stays with them.

The files were renamed (for example `emoji_u1f988.svg` became `shark.svg`) and are otherwise unchanged.
